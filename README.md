# Arcade Game Collection 🎮

Welcome to the **Arcade Game Collection**! This repository contains classic games recreated using Python and the Pygame library, inspired by my childhood favorites. Experience retro gaming with modern code while enjoying pixelated graphics, sound effects, and addictive gameplay.

## Games Included 🕹️

### 1. Rock Paper Scissors ✊✋✌️
- A digital version of the timeless classic.
- Choose between rock, paper, or scissors and compete against the computer in a best-of-three format.

### 2. Pong 🏓
- A faithful recreation of the arcade classic Pong.
- Play against a friend in this 2D table tennis game. Control paddles to keep the ball in play and score points.

### 3. Hungry Snake 🐍
- A nostalgic Snake game where you guide the snake to collect food and grow longer.
- **Cheat Codes for a Twist:**  
   - Press `Q` → Add 10 points to your score  
   - Press `S` → Increase the snake's speed  
   - Press `A` → Decrease the snake's speed

### 4. Space Fight 2D 🚀
- A multiplayer space battle game where two players compete to score points by shooting each other.
- **Player Controls:**  
   - **Player 1:** Left `Ctrl`  
   - **Player 2:** Right `Ctrl`

## 🚀 Installation & Running the Games
Ensure you have Python and Pygame installed before running the games.

### Step 1: Clone the Repository
```bash
git clone https://github.com/your-username/arcade-game-collection.git
cd arcade-game-collection
```

### Step 2: Install Pygame
```bash
pip install pygame
```

### Step 3: Run a Game
```bash
python game_name.py
```
Replace `game_name.py` with the desired game file, such as `snake.py` or `pong.py`.
